# نَسَق — تعلّم كيف تتعلّم الشبكات العصبية

تجربة عربية تفاعلية قصيرة لطلاب المرحلة الثانوية. تتدرّج من تصنيف مثال بسيط إلى عصبون وشبكة صغيرة وتدريب حقيقي وثلاث ألعاب.

## التشغيل

```sh
npm install
npm run dev
```

## التحقق

```sh
npm run typecheck
npm test
npm run build
```

الأمثلة المعروضة تعليمية ومصطنعة. المحاكاة تعمل محلياً ولا ترسل بيانات إلى خدمة خارجية.
